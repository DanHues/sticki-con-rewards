# Sticki Rolls Comic Con rewards

Visitor page: https://danhues.github.io/sticki-con-rewards/

Staff dashboard: https://sticki-con-redemption-danhues.earthyplume72.chatgpt.site/

The visitor page automatically creates a random browser pass and saves it locally. Each of the six primary social links earns one spin; all six unlock one bracelet. The visitor shows their personal QR at the booth. Staff check the shared database and confirm only newly earned rewards. Visitors may return with the same QR after visiting more pages. Concurrent or repeated scans cannot reclaim the same rewards. No printed tickets or staff code issuance are required.

Browser storage is not a permanent device identity: clearing data, private browsing, or another browser can create a new pass. Link clicks do not verify follows. Booth procedures are needed to prevent someone using multiple passes.

The staff dashboard includes click totals, unique browsers and passes, and a timeline filter for each social link, Facebook and Amazon. Reports support rolling or custom ranges up to four days and buckets as small as ten minutes, with timeline CSV export. Click counts are not social follows or purchase conversions. Offline or blocked events may be missed. Historical clicks before tracking was deployed cannot be reconstructed.

GitHub Pages hosts the public HTML, CSS, JavaScript and brand assets. The separate Sites backend hosts the database and password-protected staff dashboard. No staff password is included in this repository. Local development uses a frontend server on port 4173 and a separately configured backend on 5173.
